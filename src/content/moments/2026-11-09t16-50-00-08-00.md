# 重点项目代码与功能清单

## 一、入口与调度

| 文件 | 功能 |
|---|---|
| pipeline.py:85 | 总入口。调度各阶段、检查缓存、调用不同环境程序、保存结果 |

## 二、感知与分割（Perception）

| 文件 | 功能 |
|---|---|
| planner/observation.py:25 | 调用 Qwen 看图，输出"蓝色帽冠""橙色帽檐"等文字描述，作为分割提示 |
| perception/segment.py:178 | 调用 SAM3，接收图片+文字，输出每个部位的黑白掩码 |
| perception/tracking.py:18 | 用 CoTracker3 跟踪区域采样点，输出 xy（每点每帧位置）、visible（可见性）、region（所属区域）；检查出界/可见比例/异常跳跃，将可靠点转为区域权重 |

## 三、生成与特征捕获（Generation）

| 文件 | 功能 |
|---|---|
| generation/control.py | Force Prompting 控制。把作用位置/方向/强度转成随时间移动的高斯控制信号；当前低档 0.25、高档 0.75（控制强度，非牛顿）；49 帧、720×480、50 步去噪 |
| generation/capture.py:12 | 保存 RGB 视频 + DiT 内部特征；默认第 1 个去噪步骤、第 17 个 Transformer 块、加控制残差后的条件分支；校验 RGB 与 DiT 同源 |

## 四、核心预测模型（Models）

| 文件 | 功能 |
|---|---|
| models/estimator.py:95 | 主预测模型。在 Qwen 特征计算中加入可训练查询向量，再由输出网络预测数值；非直接问答 |
| models/queries.py:17 | 构造参数查询：部位图片特征投影 + 材料模型编码 + 参数名称编码；每部位 18 个参数查询 + 1 个部位读出向量（五模型参数数 3/3/4/4/4） |
| models/memory.py:41 | 整理动态证据：不同来源特征转到共同 512 维空间，加入时间/位置/动作/来源编码 |
| models/fusion.py:17 | 让参数查询通过注意力读取证据：softmax(query@key.T/√d)@value；加入跟踪区域权重；组内读取→跨视频/区域分配→生成更新量加回查询 |
| models/distribution.py:22 | 输出每个部位：五种材料模型概率 + 每模型参数均值 + 参数协方差 |

## 五、数值变换与训练（Training）

| 文件 | 功能 |
|---|---|
| transforms.py:140 | 参数数值变换：正参数取 log、有界参数 logit、按训练集统计量标准化；E→log(E)→z，预测后逆变换 |
| training/losses.py:8 | 损失 = 材料类型分类损失 + 参数高斯负对数似然；损失下降≠参数均值准确 |
| training/trainer.py:191 | 训练器。Qwen 基础权重与视觉编码器冻结；语言层部分注意力投影 LoRA（秩 4，lr 1e-5）；新增网络 lr 1e-4；AdamW；可训练约 3441 万参数 |
| scripts/data/verify_material_mapping.py:22 | 训练前检查：从图片像素向源三维网格发射射线取最近交点，将源部位与 SAM 掩码比对，确保标签对应正确 |

## 六、仿真（Simulation）

| 文件 | 功能 |
|---|---|
| scripts/data/prepare_geometry.py:27 | 源网格→按部位处理→修补为封闭体积→内部采样粒子→记录所属部位；当前 964 粒子（帽冠 573、帽檐 391） |
| scripts/simulation/run_drop.py:107 | 用 SOPHY/Warp 的 MPM 后端运行两次仿真（源标注材料 vs 预测材料）；重力 [0,-9.8,0]、黏着地面、步长 2.5e-6、96000 步、总时长 0.24；保存粒子位置/速度/时间/变形状态并渲染视频 |

## 七、配置文件

| 文件 | 功能 |
|---|---|
| configs/materials.yaml | 材料定义。五种材料模型的参数组合：E（杨氏模量）、nu（泊松比）、rho（密度）、yield_stress（屈服应力）、friction_angle（摩擦角） |

## 八、读代码优先顺序

estimator.py → queries.py → fusion.py → distribution.py → losses.py → trainer.py

> 这六个文件决定"材料是怎么预测和学出来的"；pipeline.py 帮助定位每一步的输入与产物。
