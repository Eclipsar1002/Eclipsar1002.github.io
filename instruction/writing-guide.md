# 写作后台使用说明

打开网站 `/admin/`，用 GitHub 登录后选择文章、项目或个人动态。

## 正文与预览

正文区域沿用 Decap 原生编辑器、工具栏和预览方式；增强功能只在编辑器上方提供“插入”“文档引用”和“草稿箱”入口。编辑区右侧显示目录，点击标题可定位到对应段落。

- 分割线：工具栏点“分割线”，或单独一行输入 `---`。
- 表格：点“表格”插入模板，然后修改 Markdown 表格的行、列与文字，右侧立即预览。当前不是可拖拽的电子表格。
- 公式：行内用 `$x^2$` 或 `\(x^2\)`；独立公式用单独两行 `$$` 包住公式，也支持 `\[...\]`。代码块里的 LaTeX 保持代码。
- 截图：正文中 Ctrl+V / ⌘V，图片先暂存，发布时与正文一起提交；也可以点“图片”选择文件。
- PDF：点“PDF 附件”在光标处插入文件链接。需要文章详情页的 PDF 预览卡片时，仍使用表单中的“PDF 附件”字段。
- 快捷菜单：在新行输入 `/`，例如 `/表`，用方向键与 Enter 选择，也可以点击项目。Esc 关闭菜单。

预览不会执行正文中的原始 HTML；自定义 HTML 和网站的特定组件以发布后的页面为准。

## 搜索与创建引用

在正文输入 `[[` 或点“文档引用”，按文章标题或路径搜索已发布的博客及本地新建的引用草稿。选择后插入 `[[路径|显示标题]]`。

找不到文章时，输入标题、可选文件夹，然后点“新建文档草稿并引用”。这只创建当前浏览器的草稿，不会自动发布空文章。打开“草稿箱”，选择新文章，补充正文后单独发布；网站重新构建后，引用链接才生效。引用索引也在网站构建时更新。

新文章的路径根据创建时的标题和文件夹生成。如果发布前更改目标标题或文件夹，应同步修改原文章中的引用。

## 文件夹

文章表单的“文件夹”支持 `学习/数学` 这样的多级路径；根目录填写 `/`。后台文章列表按嵌套文件夹整理，博客列表在存在子文件夹时显示文件夹筛选。

移动已发布文章会改变网址，旧链接和引用需要手动更新。现有文章保持原路径，新增文章以标题生成文件名。

文件夹字段只移动当前文章。同目录其他文章和附件保持原位置，避免目录整体迁移；使用相对路径引用的配图在移动文章后需检查链接，`/uploads/` 下的图片不受影响。

## 草稿自动保存

修改后约 0.6 秒自动保存到当前浏览器的 IndexedDB；Ctrl+S / ⌘S 可立即保存。保存内容包括正文、表单字段、文件夹，以及通过增强编辑器添加的图片/PDF 文件。

刷新后点“恢复草稿”继续写作；“草稿箱”可以切换或删除本地草稿。发布成功后清理对应草稿。草稿不会自动公开，也不会同步到其他设备或浏览器；清除站点数据会删除草稿。表单中另外上传的附件请在发布前检查，附件恢复以增强编辑器上传的文件为准。

## 文章目录

正文包含两个及以上二至四级标题时，详情页自动显示目录。宽屏目录位于正文右侧；较窄屏幕显示可展开的目录。点击可定位段落，滚动时会标记当前章节。
